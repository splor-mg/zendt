# Regras CLI

CLI para aplicação em bases de dados de regras de negócio construídas no modelo da ferramenta [GoRules](https://docs.gorules.io/).

Aplique regras personalizadas no formato [JDM Standard](https://docs.gorules.io/developers/jdm/standard#jdm-standard) sobre arquivos csv,excel ou JSON diretamente pelo terminal.
